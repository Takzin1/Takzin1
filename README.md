## 🛠️ How I build

- **AI-assisted, human-accountable.** I use AI coding agents for speed. Design decisions, scope and final review stay with me.
- **Tests before claims.** NaFT's IEEE repo runs 1,300+ automated assertions in GitHub Actions. These include adversarial and tamper-detection cases, a real-browser UI smoke test, and an independent read-only check against Sepolia.
- **Fail closed.** When a rule, coefficient or data source can't be verified, the system stops with `CONFIG_REQUIRED` or `EVIDENCE_REQUIRED`. It never guesses.
- **Honest scope.** Every README says what is synthetic, what is illustrative and what hasn't been validated yet. For example, NaFT's cost estimator is explicitly illustrative.

**Stack:** JavaScript / TypeScript · Node.js · Next.js · Python · Solidity (testnet) · GitHub Actions
